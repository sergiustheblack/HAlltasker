# HAlltasker

Language: [Русский](README.md) | English

Custom integration for Home Assistant: two-way task synchronization between any `todo.*` entities. Through stock HA integrations this links iCloud Reminders (CalDAV), Google Tasks, Yandex Calendar (CalDAV), and local lists.

Status: in development, MVP not released.
